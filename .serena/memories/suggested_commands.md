Core development commands (Linux):
- Build project jar: `ant`
- Clean artifacts: `ant clean`
- Build distributable zip: `ant dist`
- Generate Javadocs: `ant javadoc`
- Run application: `java -jar micropolisj.jar`
- Run translation utility: `java -cp micropolisj.jar micropolisj.util.TranslationTool`
- Inspect repo state: `git status`, `git diff`, `git log --oneline -n 20`
- File/navigation helpers: `ls`, `pwd`, `grep`, `find` (standard Linux CLI utilities).
